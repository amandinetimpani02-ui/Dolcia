# Dolcia — Micro-scénarios de D

La voix qui ouvre le Home. Jamais une explication, toujours une tension puis une révélation.
Structure fixe, contenu jamais figé : une **signature** (un mot très court, jamais expliqué),
une ou deux **répliques de tension** (chacune avec son silence avant), puis une **révélation**
poétique qui précède le vrai titre du scénario (fourni séparément par les vraies données).

**Audit éditorial du 1er août 2026 — trois corrections appliquées à l'ensemble :**
1. **Vouvoiement uniquement.** Vérifié : 150 occurrences de "vous" dans tout le produit, zéro "tu"
   avant cet audit. Les micro-scénarios avaient dérivé vers un mélange — corrigé partout.
2. **Aucune affirmation non fondée.** Toute ligne qui prétendait savoir quelque chose sur la
   personne sans donnée réelle (fatigue, manque de rire récent, habitudes, météo de demain,
   intention supposée) a été retirée ou reformulée pour ne plus l'affirmer.
3. **Aucune culpabilisation ni pression.** Les formulations du type "vous allez regretter",
   "ne perdez pas celle-ci" ont été retirées ou adoucies — Dolcia donne envie, elle ne juge jamais.

Chaque contexte est classé selon **la donnée réelle exigée** pour avoir le droit de l'utiliser.
Trois contextes (Fatigue, Envie de rire, Besoin de souffler) sont signalés comme **non utilisables
en l'état** : voir la note en fin de document.

## Pluie
*Donnée exigée : météo réelle confirmée (pluie), source API vérifiée.*

1. **Attendez…** / Tout le monde fait demi-tour. / Pas vous. → *La plage est presque à vous.*
2. **Regardez.** / La pluie vide les rues. / Elle ne vide pas tout. → *Il reste un endroit pour vous.*
3. **Chut.** / On dirait un jour à rester dedans. / On dirait, seulement. → *Il y a une autre option.*
4. **Patience.** / Ce n'est pas un jour perdu. / C'est un jour différent. → *Voilà à quoi il pourrait ressembler.*
5. **Venez.** / Les meilleurs souvenirs commencent souvent par un imprévu. → *Celui-ci pourrait en être un.*

## Grand soleil
*Donnée exigée : météo réelle confirmée (ensoleillé), source API vérifiée.*

1. **Venez.** / Le soleil ne prévient jamais quand il repart. → *Profitez-en pendant qu'il est là.*
2. **Regardez.** / Ce ciel-là, on ne le commande pas. / Aujourd'hui, il est offert. → *Voici comment en profiter.*
3. **Faites-moi confiance.** / Un ciel comme celui-ci mérite mieux qu'un balcon. → *Voici mieux.*
4. **Regardez.** / Certains jours sont faits pour rester. / Celui-ci est fait pour sortir. → *Voilà où.*

## Vent
*Donnée exigée : météo réelle confirmée (vent fort), source API vérifiée.*

1. **Écoutez.** / Ce vent-là n'abîme rien. / Il pousse. → *Vers ça, par exemple.*
2. **Venez.** / Un grand vent, ça se regarde de près, pas de la fenêtre. → *Voici où le sentir vraiment.*
3. **Regardez.** / Certains attendent que ça se calme. / D'autres en profitent. → *Voici comment.*

## Hiver
*Donnée exigée : saison réelle (calendaire), pas une supposition d'humeur.*

1. **Chut.** / L'hiver n'annule pas les journées. / Il les change juste de forme. → *Voici la vôtre.*
2. **Regardez.** / Il fait froid dehors. / Il fait bon là où je pense. → *Voici où.*
3. **Faites-moi confiance.** / Le froid rend certains lieux plus beaux, pas moins. → *Celui-ci, par exemple.*

## Couple (composition connue)
*Donnée exigée : groupe réellement enregistré comme couple (Cercle, deux adultes).*

1. **Venez.** / Ce n'est pas tous les jours qu'on a une vraie raison de se retrouver. → *En voici une.*
2. **Écoutez.** / Vous n'avez pas besoin d'une occasion. / Juste d'un moment. → *En voici un.*
3. **Chut.** / Pas besoin d'en parler à l'avance. / Laissez-vous surprendre. → *Voici la surprise.*
4. **Faites-moi confiance.** / Un coucher de soleil partagé compte plus qu'on ne le pense. → *En voici un.*

## Amis (composition connue)
*Donnée exigée : groupe réellement enregistré comme plusieurs adultes sans lien familial déclaré.*

1. **Venez.** / Un bon souvenir entre amis se fabrique, il n'arrive pas tout seul. → *En voici un début.*
2. **Écoutez.** / Les meilleures histoires qu'on raconte plus tard commencent presque toujours par une petite folie. → *En voici une, mesurée.*
3. **Faites-moi confiance.** / Ce groupe mérite mieux qu'un choix par défaut. → *Voici autre chose.*

## Retour après longtemps
*Donnée exigée : historique réel de dernière visite, au-delà d'un vrai seuil (14 jours ou plus).*

1. **Content de vous revoir.** → *J'ai gardé quelque chose pour ce retour.*
2. **Regardez.** / Beaucoup de choses ont changé depuis votre dernière visite. → *En voici une.*

## Fatigue, Envie de rire, Besoin de souffler — non utilisables en l'état

Ces trois contextes supposent un état intérieur (être fatigué, ne pas avoir ri récemment, avoir
besoin de souffler) que rien, aujourd'hui, ne permet de vérifier. Aucune donnée réelle du produit
ne mesure ça. Les utiliser reviendrait exactement à l'erreur signalée : affirmer quelque chose que
Dolcia ne peut pas savoir.

**Ils ne doivent être utilisés que si la personne l'a dit elle-même récemment** (dans une
conversation D-Coach mémorisée, par exemple) — jamais déduits par défaut. Tant que cette mémoire
n'existe pas de façon fiable, ces contextes restent en réserve, non branchés.
